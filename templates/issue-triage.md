## 分类维度
1. **类型**: bug / feature / question / docs / other
2. **紧急度**: 高（阻塞）/ 中（重要）/ 低（nice to have）
3. **复杂度**: 简单（<1h）/ 中等（1-4h）/ 复杂（>4h）
4. **建议标签**: 推荐打什么 GitHub 标签
5. **建议下一步**: 是否需要立即处理 / 等作者补充信息 / 搁置
